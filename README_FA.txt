پروژه اندرویدی «عدالت علی» — نسخه اولیه ۱٫۰

این یک پروژه واقعی Android Studio است (کد منبع)، نه فایل APK آماده نصب.
امکانات:
- صفحه اصلی تیره و ساده
- آیه سوره عنکبوت، آیه ۶۹ و ترجمه
- بخش اخبار نمونه (فعلاً خالی)
- دکمه بازکردن کانال بله
- بخش درباره برنامه
- بدون وابستگی به سایت

مهم:
1) لینک کانال در فایل app/src/main/java/ir/adalatali/app/MainActivity.java داخل مقدار BALE_LINK است.
   لینک فعلی از اطلاعات گفت‌وگوی قبلی درج شده؛ پیش از انتشار، درستی آن را آزمایش کنید.
2) برای خروجی APK، پروژه را در Android Studio باز کنید و از Build > Build Bundle(s) / APK(s) > Build APK(s) استفاده کنید.
3) ساخت APK نیاز به Android Studio/Gradle و SDK دارد؛ در این محیط فایل APK نهایی را کامپایل نکرده‌ام.
4) لوگوی فعلی نماد ترازو است؛ عکس دقیق امام علی هنوز وارد نشده چون باید تصویر موردنظر مشخص/ارائه شود.
